The Basics

Database, DBMS & RDBMS

Three core ideas you need before writing any SQL.

🗄️ Database

Database

A database is an organised collection of data stored on a computer. The data is stored in such a way that it can be easily accessed, managed and updated.

Example JVP Spark app stores all student information and marks in a database. When you click "My Result", the app quickly runs an SQL query to retrieve your marks from a table and show it to you.
👨‍💼 DBMS

DBMS

Software that manages a database. It controls how data is stored, retrieved, and updated.

Examples MySQL, MongoDB, Microsoft Access, SQLite
📊 RDBMS

RDBMS

A DBMS that stores data in tables (rows & columns). Tables can link to each other.

Examples MySQL, PostgreSQL, Oracle, SQL Server
SQL Commands

Building a School Database

Each command below builds on the last — by the end you'll have a working student database.

01 CREATE DATABASE

Creates a new, empty database. Always your first step — like making a new folder before saving files inside it.

Syntax
SQL
CREATE DATABASE database_name;
Example
SQL
CREATE DATABASE school;
Output
Query OK, 1 row affected (0.01 sec)
💡 This creates an empty database called school. No tables or data yet — we add those next.
02 USE

Tells SQL which database to work in. Run this before creating tables or querying data.

Syntax
SQL
USE database_name;
Example
SQL
USE school;
Output
Database changed
💡 Think of it as opening a folder. You must step "inside" the database before you can do anything with it.
03 CREATE TABLE

Creates a new table inside the database. You define each column's name and the type of data it holds.

Syntax
SQL
CREATE TABLE table_name (
  column1  DATATYPE,
  column2  DATATYPE
);
Example — a students table
SQL
CREATE TABLE students (
  id     INT PRIMARY KEY AUTO_INCREMENT,
  name   VARCHAR(50),
  age    INT,
  grade  VARCHAR(10)
);
Output
Query OK, 0 rows affected (0.02 sec)
💡 Common data types:  INT = whole number  ·  VARCHAR(n) = text up to n chars  ·  DATE = a date  ·  FLOAT = decimal number
04 DROP TABLE

Permanently deletes a table along with all its data. This cannot be undone.

Syntax
SQL
DROP TABLE table_name;
Example
SQL
DROP TABLE students;
Output
Query OK, 0 rows affected (0.01 sec)
⚠️ Deletes the table and everything inside it forever. To clear only the data while keeping the table, use TRUNCATE TABLE instead.
05 INSERT INTO

Adds a new row into a table. This is how you fill your table with actual data.

Syntax
SQL
INSERT INTO table_name (col1, col2)
VALUES (val1, val2);
Example — adding 3 students
SQL
INSERT INTO students (name, age, grade)
VALUES ('Arjun', 16, '10th');

INSERT INTO students (name, age, grade)
VALUES ('Priya', 15, '9th');

INSERT INTO students (name, age, grade)
VALUES ('Rahul', 17, '11th');
students table now looks like this
idnameagegrade
1Arjun1610th
2Priya159th
3Rahul1711th
💡 Text values need single quotes 'like this'. Numbers go without quotes. id fills itself automatically due to AUTO_INCREMENT.
06 DELETE FROM

Removes specific rows from a table. Always use a WHERE condition — without it, every row gets deleted!

Syntax
SQL
DELETE FROM table_name
WHERE column = value;
Example — remove Priya
SQL
DELETE FROM students
WHERE name = 'Priya';
Priya's row removed
idnameagegrade
1Arjun1610th
3Rahul1711th
⚠️ DELETE FROM students; without WHERE will wipe every single row in the table. Always double-check your condition first!
07 SELECT

The most-used command in SQL — reads and displays data from a table. It never changes your data, just shows it.

Select all columns — * means "everything"
SQL
SELECT * FROM students;
All columns returned
idnameagegrade
1Arjun1610th
3Rahul1711th
Select specific columns only
SQL
SELECT name, grade FROM students;
Only requested columns shown
namegrade
Arjun10th
Rahul11th
💡 SELECT is read-only — it never changes anything. Safe to run as many times as you like.
08 WHERE Clause

Filters results to show only rows matching a condition. Works with SELECT, DELETE, and UPDATE.

Syntax
SQL
SELECT * FROM table_name
WHERE column operator value;
Example 1 — find a student by name
SQL
SELECT * FROM students
WHERE name = 'Arjun';
Only Arjun's row returned
idnameagegrade
1Arjun1610th
Example 2 — find students older than 15
SQL
SELECT * FROM students
WHERE age > 15;
Students with age > 15
idnameagegrade
1Arjun1610th
3Rahul1711th
💡 Common operators:  = equals  ·  != not equal  ·  > greater than  ·  < less than  ·  LIKE pattern match  ·  AND / OR combine conditions
